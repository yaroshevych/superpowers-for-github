Superpowers for GitHub shortcuts

Use these on a GitHub pull request page. Shortcuts are ignored while typing in an input, editor, or comment box.

PR navigation

ShortcutAction
Shift+COpen Conversation
Shift+FOpen Files changed

Review

ShortcutAction
Shift+RMark draft pull request ready for review
Ctrl+Shift+EnterOpen the review submission menu in Files changed (⌘+Shift+Enter on Mac)

Files changed

ShortcutAction
Shift+TToggle test files viewed
Shift+DToggle documentation files viewed
Shift+GToggle generated files, snapshots, and lockfiles viewed
Shift+XToggle deleted files viewed
Shift+VToggle viewed for the current file

Diff navigation

ShortcutAction
Shift+KCollapse all; press again to expand unviewed files
j / kAfter collapsing all, expand next / previous file
Shift+EExpand all files

Viewed status is saved by GitHub. File patterns and shortcuts are built in and aren’t configurable.
